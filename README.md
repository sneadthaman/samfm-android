# 📻 SAM FM Android App

The official Android streaming app for **SAM FM**, powered by **AzuraCast**.  
Built with native Android tools and ExoPlayer for smooth, high-quality playback.

---

## 🎯 Features
- Live 24/7 streaming from `https://radio.samjanvey.com`
- Dynamic “Now Playing” track info and album artwork
- Background playback with notification controls
- Bluetooth and Android Auto integration
- No login required — open and listen instantly

---

## 🧩 Tech Stack
- **Language:** Java  
- **Audio Engine:** ExoPlayer 3  
- **Backend:** AzuraCast API  
- **Networking:** OkHttp  
- **Build System:** Gradle 8.x  
- **Min SDK:** 26 (Android 8.0)  
- **Target SDK:** 35
